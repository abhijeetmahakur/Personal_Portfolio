# Security Policy

There is no formal release or supported-version policy. Reports should identify the latest default-branch commit and whether the issue concerns the public site or local development setup.

Do not disclose vulnerability details in a public issue. If private vulnerability reporting is enabled, use **Security** > **Report a vulnerability** in this repository. If it is unavailable, ask the repository owner through an already-established private channel how to share a report; do not post exploit details publicly. Do not include credentials, private account details, or personal data in a report.

Please allow time for investigation and remediation before public disclosure. No response-time guarantee is currently defined.
